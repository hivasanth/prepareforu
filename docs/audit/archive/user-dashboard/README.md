# Archive — Legacy User Dashboard Audit Documents

## Status

Archived. Historical reference only.

## Purpose

This directory retains the legacy User Dashboard audit documents produced under
the **previous audit methodology**.

They are kept for full historical traceability and are **NOT** the
implementation source of truth.

## Supersession

The **Phase 6.XA — Page Production Certification Audit** standard completely
supersedes the previous page audit methodology.

The authoritative User Dashboard audit set now lives in [`docs/audit/`](../../)
and comprises the Phase 6.XA deliverables:

- `USER_DASHBOARD_ARCHITECTURE_AUDIT.md`
- `USER_DASHBOARD_FOUNDATION_AUDIT.md`
- `USER_DASHBOARD_UI_AUDIT.md`
- `USER_DASHBOARD_UX_AUDIT.md`
- `USER_DASHBOARD_SECURITY_AUDIT.md`
- `USER_DASHBOARD_PERFORMANCE_AUDIT.md`
- `USER_DASHBOARD_ACCESSIBILITY_AUDIT.md`
- `USER_DASHBOARD_CODE_QUALITY_AUDIT.md`
- `USER_DASHBOARD_REUSABILITY_AUDIT.md`
- `USER_DASHBOARD_IMPLEMENTATION_BACKLOG.md`
- `USER_DASHBOARD_EXECUTIVE_SUMMARY.md`

## Rules

- Do **not** delete these historical documents.
- Do **not** use these documents as the implementation source of truth.
- Do **not** create duplicate authoritative User Dashboard audits.
- Future pages must follow the Phase 6.XA Page Production Certification Audit
  standard, never the previous audit structure.
